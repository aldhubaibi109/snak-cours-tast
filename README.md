# Antrgrvaty Courses - Mini Games Collection

Welcome to the mini-games collection! This repository contains a variety of fun, classic games built with HTML/JS and Python. 

## Games Included:

* **3D Snake Arena** (`snake_3d.html`): A 3D snake game where you compete against AI opponents for food. Built with Three.js.
* **Snake Remastered** (`snake_remastered.html`): Polished 2D snake with smooth interpolated movement, 3 difficulty levels, solid/wall-wrap mode, swipe + on-screen touch controls, particle effects, and a persisted high score.
* **Snake Remastered 3D** (`snake_remastered_3d.html`): The remastered snake rebuilt in Three.js — orbiting/zooming camera, follow or whole-board view, dynamic shadows, glowing food with a point light, expanding eat rings, spark particles, wrap mode, and synthesized Web Audio sound effects (mutable with the Sound button or `M`). Requires internet on first load (Three.js from CDN).
* **Classic Snake** (`snake.html` & `snake.py`): The original 2D snake game available in both web and Python formats.
* **Racing Games** (`racing_game.html` & `racing_game_3d.html`): 2D and 3D racing experiences.
* **Tic-Tac-Toe** (`xo_game.html` & `xo_game.py`): The classic X's and O's game.

## How to Play:

* **Web Games (.html):** Simply double-click the file to open it in your favorite web browser. 
* **Python Games (.py):** Run them using Python in your terminal (e.g., `python snake.py` or `python xo_game.py`).
